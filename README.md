# Birthday‑Project
> 生日信息查询小程序

## 📖 项目简介
本项目是一款生日信息查询小程序，基于Python开发。程序支持用户输入出生日期，完成**距离下一生日剩余天数计算、已出生总天数统计、星座查询、当日运势查询并导出文件**等功能，拥有友好的人机交互界面。项目考察日期运算、数据结构与查询算法，同时预留附加功能扩展接口。

## ✨ 项目功能
1. 用户录入自己的出生日期；
2. 计算距离下一个生日剩余天数；若输入包含出生年份，则额外计算用户已经出生多少天；
3. 根据生日自动查询对应星座；
4. 查询当日星座运势，并将运势结果导出保存到本地文件；
5. 友好的控制台交互界面，包含输入校验、错误提示；
6. 预留附加功能扩展接口。
## 🧩 程序模块介绍
### 1. 日期输入与校验模块
负责接收用户输入的出生日期，对输入格式进行合法性校验，区分「带年份」和「仅月日」两种输入模式，解析得到年、月、日数据，为后续计算提供数据。

### 2. 日期计算模块
核心算法模块，基于日期运算：
- 计算距离下一次生日还有多少天；
- 如果输入包含出生年份，计算从出生到今天，用户已经出生的总天数；
- 处理闰年、跨年边界等特殊日期情况。

### 3. 星座查询模块
使用字典存储星座对应日期区间数据结构，根据用户的出生月、日，匹配查询出对应的星座名称，实现星座查询算法。

### 4. 运势查询与文件导出模块
根据用户星座获取当日运势文本，支持将运势信息写入本地文件，完成结果持久化保存。

### 5. 人机交互UI模块
控制台交互界面，提供菜单选择、提示文字、错误提醒，引导用户完成各项功能操作，提升使用体验。

### 6. 附加功能扩展模块
预留功能接口，可后续拓展，例如：生日备忘录、年龄计算、星座性格解析等拓展功能。
